# 教学源码规则

本目录继承根[AGENTS.md](../AGENTS.md)。编写任何课程源码前，读取[全局设计](../DESIGN.md)、[写作规范](../docs/planning/writing-standard.md)及对应课程目录；这些要求默认持续生效。

- 按当前章已解释的知识，小步建立完整可运行文件，不提前复制最终项目的大量代码或空分层。
- 高内聚、低耦合：一个模块承担明确职责，共用规则保持单一来源；先展示实际问题，再引入拆分与抽象。
- 新包、版本、导入、文件位置、入口与工作目录随检查点说明；提供Windows PowerShell主线及对应macOS/Linux命令，分别记录实际运行证据。
- 难懂或容易出错的地方写必要的原因注释，代码标识保持原文；长解释与生活类比在教材正文中讲清，不堆入代码文件。
- 先运行新源码并验证成功/失败/恢复，再发布检查点供页面引用；固定SHA/hash/行号，保留本步完整恢复文件，不用未来版本替代。
- 旧教材和web/fixtures不是新教学源；未完成代码不伪称运行成功，作者检查不代替真实学习者跟做。
