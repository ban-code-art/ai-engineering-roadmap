# Intent

## Requested Outcome

- 用户要先规划FastAPI基础教程：从初学知识逐步到企业工程习惯，结尾完成完整版FastAPI demo。先分区/章节/页面/前置/图/源码入口，不编写正文或项目代码。

## Scope

- FastAPI教程 /learn 的新课程结构，8分区/42独立章节、41主线/1选读、M0–M7任务管理API里程碑。
- 官方知识依据与LangChain文档组织、每章概念解释/操作/配图/源码计划、固定GitHub链接/恢复规则、小批次写作顺序。
- 同步设计入口/职责/接续与设计审阅证据。

## Non-Goals

- 本轮不写教材TSX正文、Python教学代码、完整demo、章节路由/导航，不恢复旧课。
- 不是顶部FastAPI项目实战专栏，不扩为SSO、多租户、队列或微服务企业业务系统。

## Constraints

- 一章一页、章内连续小节，全部课程不能混一页；统一LangChain风格模板。
- 新概念首次就地解释，app=FastAPI()、参数、class、Depends、yield/Session/await不能隐藏前提。
- 源码链接只有真实源运行/推送后开放，各步骤/恢复源各自固定SHA/hash；每章图有因果与视觉验收，组件演示不冒充教材图。

## Success Criteria

- 42个id/slug独立页面唯一、8分区、前置无环/不跳步、完整同步版先于异步升级。
- 每章操作/新概念/图任务/拟建源码明确，M0–M7与每批最多3主题可验收。
- 实现文件hash不变、courses源码目录不创建，官方证据/设计引用可复核。
