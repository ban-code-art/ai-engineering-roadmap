可编辑源：`web/src/components/docs/lesson-diagram.tsx`；样式：`web/src/app/lesson-diagrams.css`。

## 因果与边界

| 图 | 回答的问题 | 核心关系 | 当前源码对应 |
| --- | --- | --- | --- |
| HTTP | 客户端和服务端各发送了什么？ | 客户端 → 请求消息 → 服务端 → 响应消息 → 同一客户端；消息中请求行/状态行、头、正文分层 | F01 `requests.http` / `responses.http`；示意，不执行HTTP |
| 环境 | 终端与PyCharm为什么可能得到不同结果？ | 两个入口都分别核对工作目录、解释器；前者定位文件，后者定位环境中的包，两项相互独立 | F02 根目录 `check_environment.py` 检查 CWD、Python3.12、项目 `.venv` 与三个实际导入 |
| Python | 导入与调用有什么不同？ | 首次 import 执行 `messages.py` 顶层；def 创建函数；主程序继续；显式调用才执行函数体并返回 | F03 `imports.py` / `messages.py`；输出先 before import、loaded、after import，后 Hello, Lin |

HTTP宽屏为两端消息交换（4节点），窄屏为往返顺序（5节点，同一客户端重复表示回到起点）。环境宽屏6节点、窄屏4节点；窄屏把文件/包的从属说明放在对应设置内，不画工作目录到解释器的因果箭头。Python为6节点，模块加载与函数调用两个阶段按真实源行为排列；返回线使用虚线表示值返回，不表示异步。

## 渲染与阅读设计

- 原生SVG，无自由画布、点格、缩放控件、滚轮捕获或动画；原生details提供同内容文字解释。
- 每幅图有独立宽屏/窄屏布局。以图容器585px为阈值，不依赖浏览器全屏宽度，适配三栏文档中较窄的正文。
- 宽屏viewBox600px，正文标签15px；宽屏最小渲染宽约562px时有效字体约14.05px。窄屏viewBox280px，标签与代码15px；320px视口正文约280px时有效字体约14.89px。
- 浅色图背景为淡绿灰，深色为低亮度绿黑；普通文本与关键线分别定义双主题变量，不借用固定浅色图片。
- SVG标题/说明/箭头marker使用React useId生成，每个宽/窄变体独立后缀，避免重复ID。

## 验证证据

作者静态渲染：在 `web/` 以 `npx tsx -e` 导入 `LessonDiagram`，使用 `renderToStaticMarkup` 一次渲染全部三种图。

实测输出：3幅图、6个SVG、24个ID且全部唯一、包含原生文字说明，生成HTML24962字符。此检查确认组件可静态渲染、图中主体文字可随HTML交付，不依赖客户端JavaScript。
