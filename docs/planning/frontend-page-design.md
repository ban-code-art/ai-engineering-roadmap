# 前端页面设计：LangChain 风格统一文档框架

版本：LC-DOCS-2.0。更新：2026-10-29。

本文件是基础教程与项目实践的共同页面标准。用户已要求清除旧教程、旧示例业务和旧前端，后续内容重新编写；新仓库不保留旧教材，也不安排旧课程迁移。当前只交付统一框架、栏目入口与内部组件样例。

参考 docs.langchain.com 的 OSS Python 文档，不混用营销首页与独立API参考站：

公开仓库确认 Mintlify、Aspen、配置、定制CSS和MDX内容；最终尺寸与交互来自真实页面测量。仓库声明、页面实测与本项目适配分别记录，不声称获得全部Mintlify平台源码。本项目用Next/React/TSX与独立Node服务实现同类阅读体验，不使用Markdown/MDX教学解析，也不部署github.io。

证据保存在[官方参考目录](../evidence/langchain-reference/)。其中[仓库证据](../evidence/langchain-reference/repository-evidence.json)、[桌面浅色](../evidence/langchain-reference/desktop-light.json)、[暗色](../evidence/langchain-reference/desktop-dark.json)、[补测](../evidence/langchain-reference/review-additional-measurements.json)提供精确依据。官方站的部署提交没有证实与仓库提交相同。

## 共同的阅读外壳

基础教程 `/learn` 与项目实践 `/project` 必须使用同一个DocsShell、同一CSS/字体/token、同一导航/搜索/主题/目录组件。二者只改变栏目、标题、章节与业务数据，不能再维护另一套前端或不同主题。

普通页面是连续文档：全部小节保留，左侧分组导航、中央正文、右侧滚动目录。图与文件是局部工具，不能把默认阅读变成多栏工作台或按钮翻页向导。首页是文档门户，不是营销海报。

当前可用入口只有首页、基础教程、项目实践；旧课地址返回404。两个栏目清楚说明“内容待重新编写”，不列不存在的40章或项目阶段链接，不显示虚假完成状态。

## 外壳尺寸与响应式

| 项目 | 默认值 | 依据 |
| --- | --- | --- |
| 桌面页头 | 工具行56px + 栏目行40px，总96px | 官方实测 |
| 最外层 | max-width 1472px，居中，左右padding20px | 官方实测 |
| 左导航 | 288px，sticky top96px，独立滚动 | 官方实测 |
| 主容器 | max-width1152px，padding上40/左88/右40px | 官方实测 |
| 正文与右区域间隔 | 48px | 官方实测 |
| 右区域 | 304px，其中目录264px、左留白40px | 官方实测 |
| 目录可见顶端 | 112px，目录过长可独立滚动 | 官方152px sticky区减40px目录margin |
| 首段与页头 | margin-top32px | 官方实测 |

以内容可用宽度C计算（普通滚动条占位会使C小于innerWidth）：外层B=min(C,1472)，起点X=(C−B)/2；主宽M=B−40−288，正文x=X+20+288+88；三栏正文宽M−88−40−48−304，两栏正文宽M−88−40。

1440px有普通滚动条时正文约617px，x约396px；1920px时外层1472px、正文664px，不继续扩大。背景滚动条稳定占位，打开/关闭对话框不能导致正文跳动。

| 断点 | 呈现 |
| --- | --- |
| ≥1280px | 左导航、正文、右目录三栏 |
| 1024–1279px | 左导航与正文，文内小型目录展开 |
| <1024px | 单栏，112px固定页头，导航抽屉；正文两侧20px |
| <640px | H1 30/36px，正文仍16/28px |

手机抽屉可见宽clamp(304px,85dvw,352px)，390px约331.5px；遮罩黑色40%。内部滚动、背景锁定、Esc/遮罩关闭、焦点返回触发按钮，关闭时恢复原文档位置。过渡450ms、cubic-bezier(0.32,0.72,0,1)，reduced-motion立即切换。打开搜索前关闭导航，不叠加两个模态窗口。

## 文档组件

代码组16px圆角、轻边界、无大投影；内部2px框层，代码padding14/16px。使用Catppuccin Latte/Mocha双主题；标签位于顶沿，不用胶囊组。标签只更新本组，复制原code字符串，保留注释/缩进/换行，不复制行号或UI标记。当前块与完整文件要来自同版本；备选/恢复文件独立标名，来源/hash可展开。

关闭JS时默认内容可读，完整文件可用原生details核对。复制不可用时明确可手动选中。页头复制由受控内容数据导出连续正文及默认块，不拼整个DOM或当前标签状态。

提示圆角16px，padding16/20px，图标与内容gap12px，文字14/20px。普通正文不全部装进提示框。

## 目录、搜索、主题与状态

每小节有稳定id，目录由相同注册数据生成。滚动只更新readingSectionId，不改URL、不写history、不抢焦点。主动目录/搜索导航才写hash，并按当前页头加24px偏移。刷新、前进/后退恢复目标。

局部文件/图目标用section归属和白名单id。搜索隐藏目标时先打开目标自身/祖先details，再选中所属节点；不改变其他代码组。未知hash保留URL、返回页首、显示一次定位失败提示，不读取磁盘或执行任意组件字符串。

搜索是本地数据：只收录真实入口/已编写内容，支持中文、符号与文件名、无结果、方向键/Enter、Esc和焦点返回。桌面弹层宽640px、top54px、圆角20px，手机保留边距。Ctrl/⌘K可用，不能显示空功能或伪造AI助手。主题三态：系统/浅色/深色，覆盖文字、图、代码与提示，存储不可用仍可读。

## 图、文件与两类教程

基础教程和项目实践共用图、文件、代码组件，按内容改变数据，不引入第二套外壳。每个实际学习主题有有意义的局部图，代码创建/拆分有目录与来源；这些是后续写作要求，当前组件样例不代表课程完成。

图默认3–7节点，无编辑器点阵/自由连线/自动闪动。节点14px，选中主色；窄屏按内容宽度改纵向，不整体缩字。滚轮滚正文，局部选择/显式宽视图不接管页面；渲染失败有同数据等价说明。图明确“演示”，不能冒充真实HTTP或Python trace。

目录区分父子包含与模块关系，显示路径、用途、创建顺序、导入者及当前文件状态。未引入文件不提前展示。通用框架只定义局部接口；未来项目阶段的原子组/数据库/权限等教学契约随真实内容设计，不在组件演示中宣布已验证。

文末是回讲/相关有效链接/验证来源/统一footer。无自动上一下一大按钮或营销页尾，没有反馈后端就不显示假提交控件。

## 新内容的开发顺序

1. 保留并完善统一框架，基础与项目入口同模板；旧教程和旧教学源码不进仓库。
2. 检查内部组件样例与默认发布隔离。样例只使用 `web/fixtures/` 独立素材。
3. 重新规划首批基础教程和配套项目任务，每批2–3个主题或一个阶段。
4. 先写前置、解释、代码与恢复设计，再创建真实新样例、验证运行并接入TSX。
5. 两类教程均达到[写作规范](./writing-standard.md)与行为/阅读验收后再扩充。

没有旧课程迁移T0，也不恢复旧40章/企业源码作为正式教材。课程页面只能由受控TSX与教学数据提供，不自动解析MDX或运行时Markdown。

## 验收与剩余限制

框架验收：独立build/typecheck/tests，默认 `/framework-preview` 为404、显式预览为200；首页、基础、项目共用DocsShell；无旧首接口链接/脚本依赖；资源本地可用；字体许可随资产保留。

视觉/交互视口包括320×740、390×844、768×1000、1024×768、1280×900、1440×1000、1920×1080。比较外壳锚点/字族/字号/颜色与组件，不用不同中英文整页像素差作为唯一标准；标题替代字族单独记录。检查搜索/主题/抽屉/目录/复制/局部源码隔离、隐藏目标、失败/无JS退化。

当前框架已有主要作者检查，完整禁用JS浏览器实测仍待补齐。新教程尚未编写，初学者/PyCharm、Python行为、部署和学习效果另验收，不以框架测试代替。
